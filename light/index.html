01 / SIMULATE

Agent Environments

Test the agent in the systems it needs to use.

Give the agent access to the tools and records its task requires. Follow the actions it takes and inspect the changes it leaves behind.

  1. Choose the environment and records
  2. Give the agent a task
  3. Review its actions and changed records

02 / EVALUATE

Agent Evals

Check the work against your requirements.

An answer alone does not tell you whether the task is complete. Evaluate the result and the steps behind it to identify what the agent got right and where it failed.

  1. Define what successful work requires
  2. Assess the result and actions
  3. Investigate the failed checks

03 / GENERATE

Synthetic Data

Test situations your current data leaves out.

Create examples for the conditions you need to cover, including incomplete information and conflicting records. Review the data before using it in an environment or an evaluation.

  1. Describe the records and situations
  2. Generate and review examples
  3. Use them in environments or evaluations

See whether your changes helped.

After changing an agent’s instructions, tools, or model, give both versions the same work. Compare what they got right and wrong, then examine the steps behind any differences.

Keep testing as your agent evolves.

Use what you learn to improve the agent, test it again, and try new situations. A change that works for one case still needs to hold up elsewhere.
